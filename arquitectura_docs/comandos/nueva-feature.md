---
description: Crear una ficha de feature nueva en el backlog a partir de una idea
---

Vas a crear una ficha de feature a partir de esto: $ARGUMENTS

1. Lee `arquitectura_docs/features/_plantilla.md`.
2. Revisa `arquitectura_docs/features/` completo y asigna el siguiente ID libre.
3. Si algo del pedido es ambiguo —alcance, capa (core o cliente), criterios de
   aceptación— **pregunta antes de escribir la ficha**. Máximo 3 preguntas.
4. Completa la plantilla. Los criterios de aceptación deben ser verificables:
   nada de "que funcione bien" ni "que sea rápido".
5. Divide en tareas por área y asigna el agente de cada una.
6. Guarda en `arquitectura_docs/features/backlog/F-XXX-<slug>.md`.
7. Muestra solo el resumen: ID, título, áreas, cantidad de tareas y criterios.
